# PK-ModLoader v1.1.0

The first public release of the framework and its built-in plugin.

本框架与内置插件的首个公开发布版本。

## What's new / 更新内容

### Core loader — `dinput8.dll` / 核心加载器

- **BepInEx-style layout.** Plugins live in `mods/plugins/`, per-mod configuration in
  `mods/config/`, and runtime logs in `mods/logs/`.
  采用 BepInEx 式目录：插件放 `mods/plugins/`，配置放 `mods/config/`，日志输出到 `mods/logs/`。

- **Shipped as `dinput8.dll`.** The game executable imports `DINPUT8.dll → DirectInput8Create`
  directly, and `DINPUT8` is not a KnownDLL, so the loader is guaranteed to be loaded.
  `dinput8.dll` forwards all six system exports, so DirectInput keeps working normally.
  以 `dinput8.dll` 形式发布：游戏主程序直接导入 `DINPUT8.dll → DirectInput8Create`，且 `DINPUT8`
  不是 KnownDLL，因此加载器必定被加载；同时完整转发系统版的 6 个导出，DirectInput 功能不受影响。

- **Single-owner guard.** A named mutex makes sure the mods are loaded exactly once even if
  more than one copy of the proxy ends up installed.
  具名互斥体保证即使装有两份代理 DLL，mod 也只会被加载一次。

- **Standard DLLs welcome.** Any DLL without the SDK exports is still loaded via `LoadLibraryW`.
  未实现 SDK 导出的普通 DLL 也会通过 `LoadLibraryW` 被加载。

### Built-in plugin — `PK_ImeFix.dll` / 内置插件

- **Chinese IME lock.** Fixes keys like `W`/`A`/`S`/`D` triggering the Chinese IME candidate
  window and causing input lag. The keyboard layout is locked to US English and IME contexts
  are detached, so typing in-game stays clean.
  中文输入法锁定：解决按 `W`/`A`/`S`/`D` 误触发候选框、按键卡死的问题；键盘布局被锁定为美式英文
  并解除 IME 关联上下文，游戏内输入保持干净。

- **WinKey / sticky-key shield.** Filters `VK_LWIN` / `VK_RWIN` out of the engine's Raw Input
  stream, so `Win+W` Widgets, Windows Ink Workspace, `Win+I` Settings or the Magnifier no longer
  pop up mid-game.
  Win 键防误触：在引擎的 Raw Input 流中剔除 `VK_LWIN` / `VK_RWIN`，避免游戏中意外触发 Win+W
  小组件、Windows Ink 工作区、`Win+I` 设置或放大镜。

- **Zero system intrusion.** Everything is an in-process MinHook hook on Windows APIs, with no
  hardcoded game RVAs. Your registry, system settings and language packs are never touched, and
  the plugin is not tied to one specific game build.
  零系统侵入：全部为进程内针对 Windows API 的 MinHook 钩子，不含硬编码游戏 RVA；绝不修改注册表、
  系统设置或语言包，也不绑定某个特定游戏版本。

## Requirements / 运行要求

- Windows 10 / 11, 64-bit.
- **No Visual C++ Redistributable required.** The DLLs are fully static and import only
  `msvcrt` / `kernel32` / `user32` / `imm32`.
  **无需安装任何 Visual C++ 运行库**：产物完全静态链接，只依赖 `msvcrt` / `kernel32` / `user32` / `imm32`。
- **No game files are needed to build.** See
  [docs/GAME-FILES.md](https://github.com/JipZeonGit/PK-ModLoader/blob/main/docs/GAME-FILES.md).
  **编译本项目不需要任何游戏文件**，详见文档。

## Known limitations / 已知限制

- Windows-only, 64-bit only.
- The IME fix is aimed at Chinese Windows; on an English system it is simply a no-op.
- 仅支持 64 位 Windows；输入法修复针对中文系统，英文系统上等同于无操作。
